# HomerUI

`DesignSystem/` (text scaling, header button, empty state, title bar area, the logo) and `Components/`, the views several pages share.

## Design notes

- **Text scaling.** macOS ignores `dynamicTypeSize`, so views write `.scaledFont(.caption)` / `.scaledFont(size: 12)` instead of `.font(...)`, and `.buttonStyle(.scaledBordered)` / `.scaledBorderedProminent` / `.scaledAutomatic` on text buttons: AppKit draws push and bordered buttons and ignores any inherited font, so the style puts the scaled size inside the label. Both read the `uiFontScale` environment value, set by the public `homerUIFontScale(_:)`. At scale 1 everything renders exactly as the system draws it. Keep `.font(.system(size:))` only where a glyph sits in a fixed-size frame (`HeaderButton`)
- **`DesignSystem` is `package`, on purpose.** It is a copy of Bridge Commander's AppUI helpers of the same names (`scaledFont`, `ScaledButtonStyle`, `HeaderButton`, `EmptyStateView`, `windowTitleBarArea`). Public extension members would be visible to the host — `HomerFeature` re-exports this module, and without `MemberImportVisibility` extension members leak through transitive imports anyway — and every `.scaledFont` there would become ambiguous. `homerUIFontScale(_:)`, `HomerLogo` and the views a host uses are the only public pieces
- The web page sheet copies the instance's session cookies (`HomerClient.sessionCookies`) into the instance's own `WKWebsiteDataStore(forIdentifier:)` before loading, so the page opens signed in. The store's ID is derived from the base URL (`HomerEndpoint.webDataStoreID`, stable across launches), keeping instances apart there as the jars do; signing out also clears that store's cookies, which would otherwise stay valid until they expire. It loads the console as the top-level page: the console sends `X-Frame-Options: DENY` / `frame-ancestors 'none'`, which only an `<iframe>` would trip over. If the cookies are missing the console shows its own login page, which also works
- **The logo is generated, not drawn by hand.** `Resources/HomerLogo.png` is the app icon's drawing without the icon grid's margin and shadow, written by `scripts/make-icon.swift` together with the app icon — rerun the script rather than editing the PNG. `HomerLogo(size:)` shows it at a size scaled by `uiFontScale`, like `scaledFont(size:)`. A plain PNG, not an asset catalog: `swift build` does not compile asset catalogs
